Podman Desktop — Setup & Lifecycle

Visual guide to installation, cluster creation, daily use, and teardown

Part 1–3 · One-time Setup
1. Install Podman Desktop
podman-desktop-installer.exe
Installs Podman CLI + WSL2 integration
↓
2. Init & Start Podman Machine
podman machine init
podman machine start
Creates a WSL2 VM to run containers
↓
3. Install Kind
winget install Kubernetes.kind
Open a new terminal after install
↓
4. Create Kind Cluster
$env:KIND_EXPERIMENTAL_PROVIDER = "podman"
kind create cluster --name kafka-lab
Done once — cluster persists across reboots
↓
5. Set kubectl Context
kubectl config use-context kind-kafka-lab
Optionally set a default namespace
↓
6. Deploy Workloads
kubectl apply -f kafka.yaml
Strimzi, Kafka, Kafka UI, Topics → see README.md
Daily Use · After a Reboot or Machine Stop
Windows Reboot / Machine Stopped
Podman machine is stopped — Kind cluster is suspended
↓
Start Podman Machine
podman machine start
↓
Switch kubectl Context
kubectl config use-context kind-kafka-lab
↓
Verify Node is Ready
kubectl get nodes
kafka-lab-control-plane → Ready
↓
Resume Work
All pods, services and PVCs are restored automatically
Component Architecture
Windows Host your laptop
├── Podman Desktop GUI only — quitting stops nothing
└── Podman Machine (WSL2 VM) podman machine start/stop
    └── Kind Cluster: kafka-lab kind create/delete cluster
        └── Namespace: kafka kubectl create namespace
            ├── Strimzi Operator
            ├── Kafka Cluster (my-cluster)
            ├── Kafka UI
            └── KafkaTopic (my-topic)
Lifecycle at a Glance
Action Podman Machine Kind Cluster Kafka / Workloads
Quit Podman Desktop Running Running Running
podman machine stop Stopped Suspended Suspended
podman machine start Running Resumes Resumes
Windows reboot Stopped Suspended Suspended
kind delete cluster Running Deleted Deleted
Teardown · Full Cleanup
1. Delete Kafka Resources
kubectl delete -f kafka-topic.yaml
kubectl delete -f kafka-ui.yaml
kubectl delete -f kafka.yaml
↓
2. Uninstall Strimzi Operator
kubectl delete -f https://strimzi.io/install/latest?namespace=kafka -n kafka
↓
3. Delete Kind Cluster
kind delete cluster --name kafka-lab
↓
4. Stop Podman Machine
podman machine stop
